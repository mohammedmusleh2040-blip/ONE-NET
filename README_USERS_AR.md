# OneNet (Local Users) - شرح المستخدمين (الخيار 2)

## الفكرة
- هذه النسخة تعمل **Local**.
- تسجيل الدخول وإدارة المستخدمين تتم **محلياً داخل LocalStorage**.
- Supabase هنا يُستخدم فقط للبيانات (الفواتير/التقارير/…)، وليس لإدارة حسابات الدخول.

## أين أجد auth.users أو profiles.id؟
هذي تخص **Supabase Auth**:
- `auth.users` تظهر في: **Supabase Dashboard → Authentication → Users**.
- `profiles.id` يظهر في: **Database → Table editor → public.profiles** (عمود `id`).

✅ لكن بما أننا اخترنا **الخيار 2 (Local Users)** فطبيعي تلاقي صفحة Authentication Users فاضية.

## أول دخول (Admin)
- ادخل من النظام إلى **الإعدادات → إدارة المستخدمين**.
- ستجد مستخدم افتراضي:
  - Username: `admin`
  - Password: `admin`
- بعد الدخول غيّر كلمة المرور فوراً.

## إضافة مستخدم جديد
من **الإعدادات → إدارة المستخدمين**:
1) اختر الصلاحية (Admin / Seller / Viewer)
2) اكتب اسم المستخدم + كلمة المرور
3) فعّل الصلاحيات التي تريد
4) اضغط **حفظ**

## ملاحظة مهمة
- المستخدمين المحليين محفوظين على **نفس الجهاز ونفس المتصفح فقط**.
- إذا فتحت النظام على جهاز ثاني: لازم تسوي مستخدمين هناك أيضاً.
- إذا تبغى حسابات سحابية مشتركة بين الأجهزة: نرجع لخيار Supabase Auth لاحقاً.
